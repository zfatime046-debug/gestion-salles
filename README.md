# 🏢 Gestion des Salles

Application Java développée avec **JPA (Jakarta Persistence API)** et **Hibernate** permettant la gestion des utilisateurs et des salles via une architecture CRUD générique.

Ce projet met en pratique les bonnes pratiques du développement backend Java : séparation des responsabilités, architecture générique réutilisable, validation des données et tests unitaires.

---

# 📌 Objectifs du Projet

- Implémenter une architecture CRUD générique réutilisable
- Utiliser JPA avec Hibernate pour la persistance
- Appliquer des validations sur les entités
- Structurer un projet Maven professionnel
- Mettre en place des tests unitaires
- Comprendre la gestion du cycle de vie des entités JPA

---

# 🛠 Technologies Utilisées

- ☕ Java
- 📦 Maven
- 🗄 JPA (Jakarta Persistence)
- 🐘 Hibernate
- 🛢 H2 Database (base embarquée)
- 🧪 JUnit 5

# Ce TP permis de :
- Créer un projet Maven avec Hibernate et H2
- Configurer la génération automatique du schéma avec hibernate.hbm2ddl
- Créer deux entités (Salle et Utilisateur) avec des validations
- Implémenter des services pour les opérations CRUD
- Tester les opérations CRUD via une application principale et des tests unitaires
